# LiveDeck Releases

Official public **update-only** channel for already-installed LiveDeck clients.

## Initial installation

The first-install Windows Setup is distributed separately through the owner's protected download portal at `https://dl.irodoli.com/`. This repository is not the advertised first-install download route.

## Installed-client updates

Installed LiveDeck clients use GitHub Releases from this repository for the signed `latest.json`, update Setup/assets, checksums, and release notes. The client verifies the signed manifest, trusted HTTPS locations, expected byte size, and SHA-256 before applying an update.

The LiveDeck source code, signing private key, credentials, user data, and unrelated development artifacts are not published here.
